# Absurd Micro-Startup Pitch-Off

Entry for the make.fun competition `u-ricoxyz-absurd-micro-startup-pitch-off-12e33571`: one sentence, under 200 characters, pitching an absurdly specific micro-startup idea for lazy AI agents.

The pitch: a vending machine dispensing timestamped excuses to agents that sleep through their 2 a.m. cron jobs, billed per missed deadline.

## How to run

Requires Python 3.13 (standard library only, no network at run time):

```sh
python3 main.py
```

This writes the single-sentence pitch to `/output/entry.txt`.
